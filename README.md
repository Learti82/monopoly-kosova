# Pronat e Kosovës

A browser property-trading board game set in Kosovo, with Kosovo cities and landmarks. The whole game is in one file and needs no build step.

**Play:** open `index.html` in any browser.

- 2–6 players: people take turns on the same device, and computer players can fill the other seats
- Rules follow the printed rulebook: buying, auctions, rent and full color sets, building houses and hotels evenly (the bank has 32 houses and 12 hotels), mortgages (half price, +10% to pay off), jail (pay €50, use a card or roll doubles), Shans and Arka e Komunitetit cards, trades, debt and bankruptcy
- The game saves itself in the browser, so a reload picks up where you left off
